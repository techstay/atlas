# CSharpExamples

C# 学习示例项目，涵盖基础语法、进阶特性、函数式编程、面向对象和类型系统。

## 项目结构

```
CSharpExamples/
├── Basic/          # 基础语法
├── Advance/        # 进阶特性
├── Function/       # 函数式编程
├── Object/         # 面向对象
└── Type/           # 类型系统
```

## 运行方式

使用 `dotnet` 命令直接运行单个 C# 文件：

```bash
dotnet Basic/HelloWorld.cs
```

或通过 VS Code 任务：

1. 打开 .cs 文件
2. `Ctrl+Shift+P` → 选择 "Run C# File"

## 目录说明

| 目录     | 内容                                                                     |
| -------- | ------------------------------------------------------------------------ |
| Basic    | 基础语法：变量、条件、循环、运算符、枚举、异常等                         |
| Advance  | 进阶特性：异步、LINQ、模式匹配、扩展方法                                 |
| Function | 函数定义与使用                                                           |
| Object   | 面向对象：类、继承、多态                                                 |
| Type     | 集合类型：List、Dict、Set、Queue、Stack、String、Tuple、Record、Nullable |

## 环境要求

- .NET 10 SDK
