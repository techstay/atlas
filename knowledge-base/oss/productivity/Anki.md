## 简介 📚

Anki 是一个开源免费的卡片式记词软件。核心原理是间隔重复（Spaced Repetition），根据记忆曲线动态安排复习间隔，适合英语、日语等多语言词汇记忆 🌍。

软件本身不包含任何内容，需要通过导入牌组（`.apkg`）来使用。

## 下载和安装 💻

[Anki 官网](https://apps.ankiweb.net/)，支持全平台：Windows、Linux、macOS、Android、iOS。跨平台同步通过 AnkiWeb 账户实现 🔄。

## 牌组 🃏

牌组就是 Anki 的生词本，从社区获取。

### 查找牌组 🔍

[AnkiWeb 共享牌组](https://ankiweb.net/shared/decks)，按语言或用途筛选，也支持搜索。

### 推荐牌组 ⭐

- [4000 Essential English Words (all books)](https://ankiweb.net/shared/info/1738590355)，英英释义，约 4000 词，附带读音和图片 📖
- [JLPT N1～N5 单词＋补充（含语音、例句）](https://github.com/5mdld/anki-jlpt-decks)，14000+ 条笔记，覆盖 N1-N5，含语音和例句 🗾
- [Japanese course based on Tae Kim's grammar guide & anime](https://ankiweb.net/shared/info/1537804347)，2000+ 例句和语音，例句全部来自日本动画 🎬

### 导入牌组 📥

菜单栏「文件 → 导入」，选择 `.apkg` 文件即可。部分牌组有使用说明，导入后请查看并按说明设置。

## 牌组设置 ⚙️

不同牌组的推荐参数不同。导入后可在牌组选项中调整：

- **New Cards / Day** 🆕：每天学习的新卡片数量
- **Reviews / Day** 📖：每天复习上限
- **Lapses** 🔁：复习失败时的重试间隔和步骤
- **Display Order** 📋：卡片显示顺序

## 开始记词 🎯

导入牌组后，点击牌组 → 选择章节 → 开始学习。

流程：

1. 显示卡片正面（单词/句子）📝
2. 回忆含义后点击「显示答案」💡
3. 根据掌握程度选择按钮：Again（又不会）/ Hard（难）/ Good（好）/ Easy（简单）
4. 不会的单词会高频出现，简单的则会拉长间隔 📈

### 快捷键（桌面端） ⌨️

- **空格**：显示答案
- **1 / 2 / 3 / 4**：选择四个选项
- **R**：播放音频（牌组含音频时）🔊

## 复习功能 🧠

Anki 的核心是**间隔重复算法（SRS）** 🌀，根据遗忘曲线自动安排复习时间。通常情况下，答对的卡片当天不会再出现。

如需本日内重复学习已学内容，有以下三种方式。

### 方法一：自定义复习（Custom Study） 🔧

最推荐的方式，不破坏原有算法进度。

1. 在主界面点击目标**牌组**
2. 点击下方的 **自定义复习（Custom Study）** 按钮
3. 选择场景：
   - **前置针对性复习（Preview upcoming cards）**：预习后面的卡片 👀
   - **按特定状态复习**：筛选指定标签/状态的卡片
4. 如需提取今天已复习的卡片，创建筛选牌组，搜索条件输入：
   - `rated:1`：今天所有评价过的卡片 📅
   - `rated:1 is:new`：今天学习的新卡 🆕

筛选后会生成蓝色**筛选牌组（Filtered Deck）**，可在其中无限次重复学习。

> 💡 筛选牌组设置中，**取消勾选**「根据在此牌组中的回答更新原牌组的日程」，重复操作的回答不会影响卡片原本的复习间隔。

### 方法二：调整学习阶段（Learning Steps） 📊

让卡片本身在当天多出现几次。

| 参数             | 默认 (1m 10m)  | 强化 (5m 30m 120m)     |
| ---------------- | -------------- | ---------------------- |
| 当日单卡复习次数 | 至少 2 次      | 至少 3 次              |
| 通关间隔         | 1 分钟 → 10 分钟 | 5 分钟 → 30 分钟 → 2 小时 |
| 适用场景         | 普通词汇       | 易混淆的复杂知识       |

调整步骤：

1. 牌组右侧 **齿轮图标 → 选项（Options）**
2. 找到 **新卡片（New Cards）** 或 **重新学习（Relearning）** 模块 🔄
3. 修改**学习阶段（Learning Steps）**，如输入 `5m 30m 2h`

### 方法三：重设本日进度 🔄

将今日所有复习过的卡片恢复到未学习状态。

1. 进入 **浏览（Browse）** 窗口
2. 左侧选择牌组，搜索栏输入 `rated:1`
3. **Ctrl+A** 全选
4. 右键 → **卡片状态 → Reset**

> ⚠️ 此操作会抹去当日复习进度，算法视作未学内容，请谨慎使用。

## 插件 🔌

[AnkiWeb 插件库](https://ankiweb.net/shared/addons)，找到插件后可获取插件 ID（一串数字）。

安装方式：菜单栏「工具 → 插件 → 获取插件」，粘贴 ID 安装，重启生效 🔄。

### 推荐插件 💎

- [Review Heatmap](https://ankiweb.net/shared/info/1771074083)（ID: 1771074083），模仿 GitHub 提交热力图，可视化每日学习记录 📊

## 多端同步 🌐

1. [AnkiWeb](https://ankiweb.net) 注册账户
2. Anki 中「工具 → 设置 → 同步」，登录账户
3. 在其他设备登录同一账户即可自动同步牌组和学习记录 📱

> ⚠️ Anki 资金有限，会删除不活跃账户数据。如长期不用，请手动备份牌组 💾。
