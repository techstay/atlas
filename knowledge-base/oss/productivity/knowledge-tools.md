## AFFiNE

「文档 + 无限白板」双模式融合的知识库 🎨。同一份笔记可以在线性文档和自由画布之间一键切换，块级编辑器体验接近 Notion，并支持类 Figma 的多人实时协作。

- 🏠 官网：<https://affine.pro/>
- 📦 源码：<https://github.com/toeverything/affine>
- 🎯 侧重点：**创意脑暴、视觉化思维与团队协作**——适合需要把零散想法变成结构化文档，或和团队在白板上涂鸦规划的用户。

## AppFlowy

主打隐私与性能的本地优先笔记，Notion 的开源替代品 🔒。Flutter + Rust 架构带来跨端一致的流畅体验，支持看板、表格等多视图，数据 100% 留在本地。架构高度模块化，开发者可以用 Rust 编写自己的插件。

- 🏠 官网：<https://www.appflowy.com/>
- 📦 源码：<https://github.com/AppFlowy-IO/AppFlowy>
- 🎯 侧重点：**个人隐私、本地数据控制与看板式项目管理**——适合喜欢 Notion 的表格和多视图，但想把数据锁在自己硬盘里的用户。

## Tolaria

AI 时代的「文件大于应用」型知识库 🤖。纯 Markdown + YAML Frontmatter 存储，每个 Vault 即是一个 Git 仓库，用版本历史取代回收站。内置 MCP 服务器，让 Claude Code 等 AI Agent 能原生读写整个笔记库；用 Type 和智能视图替代传统文件夹分类。

- 📦 源码：<https://github.com/tolaria/tolaria>
- 🎯 侧重点：**AI 工作流集成、开发者与键盘流极客**——适合重度依赖 Markdown 和 Git，想让 AI 智能体直接跟知识库打交道的用户。
