# 📦 Open Source Software (OSS) 开源软件大百科

本分类目录系统化整理和收录了各类优秀的**开源第三方工具、软件及框架**的使用指南、部署实践与深度集成笔记。主要收录了 **Git/GitHub 协作流程、Docker 与 Podman 容器引擎、PM2 应用挂载、Tauri 跨平台 GUI、Ollama 本地大模型及 VSCode 配置**等开发工具，以及 **Fish/Nushell Shell 终端、Nala 包管理、常见现代 CLI 代替工具、KeePassXC 安全密码锁、Telegram 效率插件、青龙自动化定时面板与 OpenClaw 智能体网关**等。
