# 📦 Open Source Software (OSS) 开源软件大百科

本分类目录系统化整理和收录了各类优秀的**开源第三方工具、软件及框架**的使用指南、部署实践与深度集成笔记。

## 🏗️ 推荐项目速览

### 开发工具

- [lukilabs/beautiful-mermaid](https://github.com/lukilabs/beautiful-mermaid) - 美化 Mermaid 图表输出，支持自定义主题与样式，让技术文档中的流程图、时序图更加美观专业。
- [Nokse22/ascii-draw](https://github.com/Nokse22/ascii-draw) - 在终端中用字符绘制草图，支持自由绘画、形状工具与多种导出格式，ASCII 艺术爱好者的利器。
- [Wilfred/difftastic](https://github.com/Wilfred/difftastic) - 结构化差异对比工具，能理解代码语法树而非仅做文本行比对，让 diff 结果更具可读性。
- [agnosticeng/agx](https://github.com/agnosticeng/agx) - 跨数据库统一管理工具，提供一致的 SQL 客户端界面，支持多种数据库引擎的查询与管理。

### 监控与数据

- [prometheus/prometheus](https://github.com/prometheus/prometheus) - 开源系统监控与告警工具包，内置时序数据库，是云原生可观测性的事实标准。
- [influxdata/influxdb](https://github.com/influxdata/influxdb) - 高性能时序数据库，专为指标、事件和实时分析设计，广泛用于 DevOps 与 IoT 场景。

### 前端与设计

- [jackyzha0/quartz](https://github.com/jackyzha0/quartz) - 快速、开箱即用的静态站点生成器，可将 Markdown 内容转化为功能完备的网站。

### 效率与工具

- [super-productivity/super-productivity](https://github.com/super-productivity/super-productivity) - 高级待办事项管理应用，集成 Timeboxing 与时间追踪功能，助力深度工作。
- [ebonnal/streamable](https://github.com/ebonnal/streamable) - Python 同步/异步可迭代流工具库，简化流式数据处理管道的构建。
- [marimo-team/marimo](https://github.com/marimo-team/marimo) - Python 响应式 Notebook，支持可复现实验、SQL 查询、脚本执行与应用部署。

### 安全与环境

- [dmno-dev/varlock](https://github.com/dmno-dev/varlock) - AI 安全的 .env 文件管理：为 Agent 提供 Schema 约束，为人类保留 Secrets 访问。
- [dotenvx/dotenvx](https://github.com/dotenvx/dotenvx) - 来自 `dotenv` 作者的安全环境变量管理工具，支持加密与多环境管理。

### 系统与桌面

- [calesthio/Crucix](https://github.com/calesthio/Crucix) - 集成全球地图的智能 Agent 工具，支持地理位置相关的自动化任务与可视化。
- [sansan0/TrendRadar](https://github.com/sansan0/TrendRadar) - 多源新闻聚合推送工具，支持自定义关键词过滤与定时推送。
