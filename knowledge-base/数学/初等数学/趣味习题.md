## 趣味题

### 一筐鸡蛋

1 个 1 个拿，正好拿完；2 个 2 个拿，还剩 1 个；3 个 3 个拿，正好拿完；4 个 4 个拿，还剩 1 个；5 个 5 个拿，还差 1 个；6 个 6 个拿，还剩 3 个；7 个 7 个拿，正好拿完；8 个 8 个拿，还剩 1 个；9 个 9 个拿，正好拿完。

问：筐里最少有几个鸡蛋？

---

#### 解答

**整理条件，建立同余方程组：**

设筐中鸡蛋数为 $n$，由题意得：

$$
\begin{cases}
n \equiv 0 \pmod{2} \quad \text{（2个2个拿，还剩1个）→ } n \equiv 1 \pmod{2}\\
n \equiv 0 \pmod{3} \quad \text{（3个3个拿，正好拿完）}\\
n \equiv 1 \pmod{4} \quad \text{（4个4个拿，还剩1个）}\\
n \equiv 4 \pmod{5} \quad \text{（5个5个拿，还差1个）}\\
n \equiv 3 \pmod{6} \quad \text{（6个6个拿，还剩3个）}\\
n \equiv 0 \pmod{7} \quad \text{（7个7个拿，正好拿完）}\\
n \equiv 1 \pmod{8} \quad \text{（8个8个拿，还剩1个）}\\
n \equiv 0 \pmod{9} \quad \text{（9个9个拿，正好拿完）}
\end{cases}
$$

**化简约束：**

- $n \equiv 0 \pmod{9}$ 且 $n \equiv 0 \pmod{7}$
  → $n$ 是 $\text{lcm}(7, 9) = 63$ 的倍数，即 $n = 63m$
- $n \equiv 1 \pmod{8}$
  → $63m \equiv 1 \pmod{8}$，即 $7m \equiv 1 \pmod{8}$
  → 因为 $7 \times 7 = 49 \equiv 1 \pmod{8}$，所以 $m \equiv 7 \pmod{8}$
  → $m = 7, 15, 23, 31, \ldots$

**逐一验证 $n \equiv 4 \pmod{5}$：**

| $m$ | $n = 63m$ | $n \mod 5$ | 是否满足 |
| --- | --------- | ---------- | -------- |
| 7   | 441       | 1          | ❌       |
| 15  | 945       | 0          | ❌       |
| 23  | **1449**  | **4**      | ✅       |

**验证 $n = 1449$ 满足所有条件：**

| 条件     | 计算                      | 结果    |
| -------- | ------------------------- | ------- |
| $\div 2$ | $1449 = 724 \times 2 + 1$ | 剩 1 ✅ |
| $\div 3$ | $1449 = 483 \times 3$     | 正好 ✅ |
| $\div 4$ | $1449 = 362 \times 4 + 1$ | 剩 1 ✅ |
| $\div 5$ | $1449 = 289 \times 5 + 4$ | 差 1 ✅ |
| $\div 6$ | $1449 = 241 \times 6 + 3$ | 剩 3 ✅ |
| $\div 7$ | $1449 = 207 \times 7$     | 正好 ✅ |
| $\div 8$ | $1449 = 181 \times 8 + 1$ | 剩 1 ✅ |
| $\div 9$ | $1449 = 161 \times 9$     | 正好 ✅ |

**筐里最少有 $\boxed{1449}$ 个鸡蛋。**
