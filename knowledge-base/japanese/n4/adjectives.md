形容词分为一类形和二类形。

## 做谓语

| 敬体形       | 否定                   | 过去形式       | 过去否定                     |
| ------------ | ---------------------- | -------------- | ---------------------------- |
| 可愛いです   | 可愛くないです         | 可愛かったです | 可愛くなかったです           |
| にぎやかです | にぎやかではありません | にぎやかでした | にぎやかではありませんでした |

| 简体形     | 否定             | 过去形式       | 过去否定             |
| ---------- | ---------------- | -------------- | -------------------- |
| 可愛い     | 可愛くない       | 可愛かった     | 可愛くなかった       |
| にぎやかだ | にぎやかではない | にぎやかだった | にぎやかではなかった |

## て形

| 一类形 | 一类て形 | 二类形 | 二类て形 |
| ------ | -------- | ------ | -------- |
| 新しい | 新しくて | 簡単   | 簡単で   |
