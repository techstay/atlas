# 🚀 Tech 前沿技术与实用网络书签

本分类包含前沿技术开发规范、软件协议以及网络优质资源的导航。

## 🚀 科技与航天

- [Next Spaceflight](https://nextspaceflight.com/) — 火箭发射日程表，追踪全球航天发射任务。

## 📚 学习资源

- [Red Blob Games](https://www.redblobgames.com/) — 计算机科学可视化教程，通过互动网页讲解算法、数学和游戏开发。

## 📜 许可证选择

- [SPDX 列表](https://spdx.org/licenses/) — 标准化软件许可证名称列表，便于在开源项目中引用。
- [ChooseALicense](https://choosealicense.com/) — GitHub 官方创建的开源代码项目协议选择指南。
- [Creative Commons](https://chooser-beta.creativecommons.org) — Creative Commons 许可证选择工具，选好协议后可查看协议内容，只需在网页添加 `legalcode.txt` 后缀即可获取纯文本版本。

## 🖼️ Favicon 工具

- [Favicon Generator](https://www.favicon-generator.org) — 在线生成网站图标（favicon）的工具。
- [Favicon.io Emoji Favicons](https://favicon.io/emoji-favicons/collision/) — 使用 Emoji 生成 favicon 的在线服务。
