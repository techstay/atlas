# 🇬🇧 English 英语学习笔记

本分类记录和英语学习相关的笔记。

## 📖 学习资源

- [Oxford 3000 & 5000](https://www.oxfordlearnersdictionaries.com/wordlists/oxford3000-5000) — 牛津核心词汇表，收录英语最重要的 3000/5000 个单词。
- [YouGlish](https://youglish.com/) — 英语发音练习工具，通过 YouTube 视频实时查询单词发音。
- [巴别英语](https://www.babelabc.com/) — 在线英语听力口语学习平台，提供原声影视材料练习。
- [英语自学经验](https://bewaters.me/limxtop/2021/08/18/English-introduction/) — 英语自学方法分享，包含方法和资源推荐。
