## Reasonix

[Reasonix](https://esengine.github.io/DeepSeek-Reasonix/index.html) 是专为 DeepSeek 设计的智能体，能充分利用 DeepSeek 的长上下文和低价缓存，降低使用成本。

### 开始使用

安装 CLI。

```sh
npm install -g reasonix && reasonix code
```

桌面端从这里下载<https://esengine.github.io/DeepSeek-Reasonix/download.html>
