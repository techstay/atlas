### 🕷️ Web 抓取与 AI 数据

- [firecrawl/firecrawl](https://github.com/firecrawl/firecrawl) — 面向 AI 的 Web Data API，可将整站内容转换为 LLM 可用的 Markdown 或结构化数据。
- [firecrawl/firecrawl-mcp-server](https://github.com/firecrawl/firecrawl-mcp-server) — Firecrawl 的 MCP 服务器，为 LLM 客户端提供网页抓取、搜索与深度爬取能力。
- [jina-ai/reader](https://github.com/jina-ai/reader) — 通过简单 URL 前缀将任意网页转换为 LLM 友好的输入格式，即插即用。
- [unclecode/crawl4ai](https://github.com/unclecode/crawl4ai) — 面向 LLM 的开源 Web 爬虫与抓取框架，专为 AI 数据采集场景优化。
- [D4Vinci/Scrapling](https://github.com/D4Vinci/Scrapling) — 自适应 Web 抓取框架，能智能应对页面结构变化，稳定提取目标数据。
- [markdown.new](https://markdown.new) — 将任意网页快速转换为干净 Markdown，支持自动 fallback 与整站爬取。

### 🌐 浏览器自动化

- [lightpanda-io/browser](https://github.com/lightpanda-io/browser) — 从零用 Zig 编写的超轻量无头浏览器，专为 AI 自动化与爬虫场景设计，极致省资源。
- [pasky/chrome-cdp-skill](https://github.com/pasky/chrome-cdp-skill) — 让 AI 直接连接你当前正在使用的 Chrome 标签页，通过 CDP 协议实现真实浏览器操作。
- [hangwin/mcp-chrome](https://github.com/hangwin/mcp-chrome) — Chrome MCP Server，将 Chrome 浏览器功能暴露给 AI 助手调用。
- [ChromeDevTools/chrome-devtools-mcp](https://github.com/ChromeDevTools/chrome-devtools-mcp) — Chrome DevTools 官方 MCP 服务器，为 AI 编码代理提供 DevTools 能力。
- [pinkpixel-dev/web-scout-mcp](https://github.com/pinkpixel-dev/web-scout-mcp) — MCP 网页搜索与内容提取扩展，集成 DuckDuckGo 搜索与 URL 内容提取。
