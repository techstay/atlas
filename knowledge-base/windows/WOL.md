# 📱 手机远程唤醒电脑（Wake on LAN）

通过 **Wake on LAN（WOL）** 技术，可以让电脑在关机或睡眠状态下，通过手机发送「魔术封包」远程开机。它最适合用于家庭局域网内唤醒电脑，例如人在客厅、床上或另一台设备前，需要临时启动主机。

> [!note] 前提条件
> 🔌 WOL 通常要求电脑使用**有线网卡**连接路由器。部分无线网卡支持 Wake on WLAN，但兼容性较差，不建议作为首选方案。

## 🧭 配置流程

整体需要完成三件事：

1. 🧩 在 BIOS 中允许主板和网卡在关机后保持待机供电。
2. 💻 在 Windows 中允许网卡接收魔术封包并唤醒电脑。
3. 📲 在手机 App 中填写电脑的 MAC 地址，并向局域网发送唤醒包。

## 🛠️ 1. BIOS 设置

以下路径以华硕主板为例，不同品牌主板的菜单名称可能略有差异。

1. 🚪 开机或重启时连续按 `Del` 或 `F2` 进入 BIOS。
2. ⚙️ 按 `F7` 切换到高级模式（Advanced Mode）。
3. 🔎 进入 `Advanced` -> `APM Configuration`。
4. ✅ 开启 `Power On By PCI-E`。
   - 有些主板会显示为 `Resume By PME`、`PCI-E Device Power On` 或类似名称。
5. ❌ 关闭 `ErP Ready`。
   - 如果开启 ErP，关机后网卡可能会被彻底断电，导致无法唤醒。
6. 💾 按 `F10` 保存设置并重启。

> [!tip]
> 🔋 如果想用智能插座断电再上电的方式开机，可以同时开启 `Restore AC Power Loss`、`AC Back` 或类似选项，并设置为来电后自动开机。

## 💻 2. Windows 设置

### 🧩 配置网卡唤醒

1. 🪟 右键点击开始菜单，打开「设备管理器」。
2. 🌐 展开「网络适配器」。
3. 🔌 找到正在使用的有线网卡，通常名称中带有 `Intel`、`Realtek` 或 `Ethernet`。
4. 🧰 右键打开「属性」。
5. ✅ 在「高级」选项卡中，开启以下项目：
   - `Wake on Magic Packet`
   - `魔术封包唤醒`
   - `关机网络唤醒`
   - 如果存在 `Wake on pattern match`，可以不开启，避免误唤醒。
6. 🔋 在「电源管理」选项卡中，勾选：
   - 「允许此设备唤醒计算机」
   - 「只允许魔术封包唤醒计算机」

### ⚡ 关闭快速启动

Windows 的快速启动可能会让关机状态介于休眠和关机之间，导致部分网卡无法正常接收 WOL 信号。

路径：

```text
控制面板 -> 电源选项 -> 选择电源按钮的功能 -> 更改当前不可用的设置
```

取消勾选「启用快速启动」，然后保存。

### 📌 记录电脑信息

打开命令提示符或 PowerShell，执行：

```powershell
ipconfig /all
```

找到有线网卡，记录以下信息：

- 🆔 `物理地址`：也就是 MAC 地址，例如 `AA-BB-CC-DD-EE-FF`。
- 🏠 `IPv4 地址`：例如 `192.168.1.23`。

> [!important]
> 📌 手机端真正必须填写的是 **MAC 地址**。IP 地址可能会变化，建议在路由器里给电脑设置固定 DHCP 地址，避免后续排查麻烦。

## 📲 3. 手机端设置

手机和电脑处于同一个局域网时，配置最简单。

1. 📦 安装支持 WOL 的手机 App。
   - 🤖 Android：搜索 `Wake On LAN`。
   - 🍏 iOS：搜索 `Wake on LAN` 或 `WOL`。
2. 📝 新建设备，填写：
   - 🏷️ 名称：自定义，例如 `Desktop`。
   - 🆔 MAC 地址：填写前面记录的物理地址。
   - 📡 IP 或广播地址：优先使用 `255.255.255.255`，也可以使用局域网广播地址，例如 `192.168.1.255`。
   - 🚪 端口：通常填写 `7` 或 `9`。
3. 🚀 电脑关机后，在手机 App 中点击唤醒按钮。

如果配置正确，电脑的有线网口在关机后通常仍会亮灯或闪烁，这是网卡待机供电正常的表现。✨
