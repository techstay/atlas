## 服务端设置

开启来宾账户。

```sh
Enable-LocalUser -Name "Guest"
```

## 启用共享

在要共享的文件夹上右键，开启共享，启用 `Everyone` 账号，并设置权限。

## 客户机访问

在客户端用 `Guest` 账户登录。

---

## Everyone 组与 Guest 账户关系

Everyone 组包含 Guest 账户（启用时），但实际访问受网络验证机制限制。

### 组成员关系

```
Everyone = 已认证用户 + Guest 用户 + 匿名用户
```

### 网络访问模型

#### Classic 模式（Windows 10/11 默认）

- 使用客户端当前登录凭据进行身份验证
- 服务端无对应账户或密码不匹配时直接拒绝
- 不会自动降级到 Guest 账户
- Guest 即使启用也可能被拒绝访问

#### Guest-only 模式

- 未通过验证的用户自动映射为 Guest
- Guest 可访问 Everyone 有权限的资源

### 访问行为对照表

前提：Everyone 读取权限已启用，Guest 账户已启用

| 客户端条件               | Classic 模式     | Guest-only 模式      |
| ------------------------ | ---------------- | -------------------- |
| 同名同密码账户存在       | 以该账户身份访问 | 访问（身份为 Guest） |
| Guest 登录               | 拒绝（网络受限） | 允许                 |
| 其他账户（服务端无对应） | 拒绝             | 允许（降级为 Guest） |

### 匿名访问配置

#### 方法 1：本地安全策略

```
secpol.msc / gpedit.msc
计算机配置 → Windows 设置 → 安全设置 → 本地策略 → 安全选项
→ "网络访问：本地账户的共享和安全模型" = 仅来宾 - 本地用户以来宾身份身份验证
```

#### 方法 2：关闭密码保护

```
控制面板 → 网络和共享中心 → 高级共享设置
→ 所有网络 → 关闭密码保护共享
```

### 故障排查

Guest 无法访问时的检查项：

1. Guest 账户状态：`Get-LocalUser -Name "Guest"`
2. Everyone 权限是否包含读取
3. 网络访问模型配置
4. 密码保护共享状态
5. 网络发现和文件共享是否启用
