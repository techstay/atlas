# 🪟 Windows 系统管理与高效折腾

本分类目录深度整理了 Windows 系统的进阶玩法与维护技巧。主要收录了 **WSL2 架构设计与 Arch Linux 深度美化**、**Windows Terminal/MSYS2/C++ 编译工具链与 Sandbox 沙盒环境**等开发配置、**Scoop 命令行包管理器与 Sysinternals 系统级诊断工具**、**系统蓝屏 SFC/DISM 修复、BCD 引导故障排查与 VHD 部署免分区双系统**，以及 **局域网共享权限、隐藏式软热点、系统臃肿清理及小狼毫输入法同步配置**。
