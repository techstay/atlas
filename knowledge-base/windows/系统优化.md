# 系统优化

## 电脑卡顿诊断

### 问题描述

关闭前台程序或快速切换应用时卡顿数秒。

### 诊断过程

1. **硬件检查**：Ryzen 7 9700X + 64GB RAM + NVMe SSD — 硬件无问题
2. **内存使用**：48% 使用率，33GB 可用 — 内存充足
3. **进程排查**：发现 WSL (1.9GB) + VMware (922MB) 后台运行
4. **分页文件**：仅使用 230MB — 未触及内存瓶颈

### 根本原因

**WSL 和 VMware 虚拟机**在后台持续占用资源，切换应用时触发内存竞争。

### 解决方案

- 关闭 WSL：`wsl --shutdown`
- 或关闭 VMware 进程
- 不用时保持虚拟机关闭，不要后台常驻

### 经验总结

- 虚拟机是资源消耗大户，即使不开游戏也可能导致系统响应变慢
- 内存充足时，Memory Compression 是正常的优化机制，不是问题
- 开机启动项过多（24 个）会拖累系统，可酌情禁用
