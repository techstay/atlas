## 开启独立搜索栏

在 edge 的快捷方式后面添加下面的参数，就可以开启独立搜索栏了。

```txt
--enable-features=msSearchBoxInToolbar,msSearchBoxInToolbarSearchInteractionTrigger,msSearchBoxInToolbarShownTrigger,msFavoritesOpenInNewTabSetting
```
