# 🖥️ 系统信息

## 🔍 HWiNFO

HWiNFO 是一款很适合查看硬件信息和传感器数据的 Windows 工具。可以从 [官网下载安装](https://www.hwinfo.com/download/)，也可以直接通过命令行安装。

```sh
winget.exe install --id "REALiX.HWiNFO" --exact --source winget --accept-source-agreements --disable-interactivity --silent --accept-package-agreements --force
```
