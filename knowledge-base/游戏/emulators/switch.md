# switch

## Ryujinx 模拟器

Ryujinx 是一个使用 C#编写的实验性 switch 模拟器。

### 安装

从官网可以下载 Ryujinx 模拟器，地址 <https://ryujinx.app/>。

### 配置

和 yuzu 模拟器一样，Ryujinx 首先需要配置 key 和固件。

#### key

首先下载 keys，下载完成后解压得到 `prod.keys` 文件。。

- https://prodkeys.net/v27/
- <https://drive.google.com/drive/folders/1KAym-RpGIDuJiSmMLmpCtGVbhLm4VjTZ?usp=sharing>。

首先点击*菜单栏 ->File->打开 Ryujinx 文件夹*，然后在 system 子文件夹中复制 `prod.keys` 文件，就配置好了 key。

#### 固件

然后还要下载固件。下载完成后解压，可以得到一大堆文件。

- https://github.com/THZoria/NX_Firmware/releases

然后点击*菜单栏 ->Tool->Install Firmware->Install a firmware from directory*，找到刚才解压的固件文件夹，就可以安装固件了。固件安装完毕之后，可以在模拟器下方状态栏的最右边查看固件版本号。

#### 游戏列表

打开*菜单栏 ->Options->Settings*，在 General 标签中添加要使用的游戏目录即可。

### 安装更新/DLC

Ryujinx 有内置的 DLC 支持，右键点击要安装 DLC 的游戏，选择*Manage DLC*或者*Manage Title Updates*，然后选择要安装的更新即可。
