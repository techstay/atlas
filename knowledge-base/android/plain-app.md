# PlainApp - 安卓设备网页管理工具

## 项目概述

PlainApp 是一款免费开源的 Android 应用，可以将你的手机变成一个自托管的管理中心，你可以从任何网页浏览器安全地访问和管理手机上的内容。所有数据都仅在本地网络内传输，不会离开你的设备，保障隐私安全。

## ✨ 核心特性

- 🔒 **100% 本地运行**：数据永远不会离开你的网络，没有云端存储
- 🔐 **端到端加密**：所有连接都通过 TLS + XChaCha20-Poly1305 加密保护
- 🆓 **完全免费无广告**：没有内购，没有升级推销，永久免费使用
- 📱 **丰富的管理功能**：

| 功能分类 | 支持的功能                      |     |
| ---- | -------------------------- | --- |
| 媒体管理 | 文件管理、音乐播放器、图片查看、视频播放、音频管理  |     |
| 内容管理 | 笔记、RSS 阅读器、短信查看、通话记录、联系人管理 |     |
| 实用工具 | 屏幕镜像、聊天功能、加密连接             |     |

## 🚀 使用方法

1. 在手机上安装并打开 PlainApp
2. 应用会在手机上启动一个本地 Web 服务
3. 在同一局域网下的其他设备浏览器中访问应用显示的地址
4. 即可通过网页端管理你的 Android 设备
