# 🌐 Network 网络通信与安全连接

本分类专注于计算机网络技术、内网穿透与远程接入、网关防护以及软路由系统的折腾笔记。主要收录了 **AdGuard Home 广告拦截与 Cloudflare 解析中转**等网关解析服务、**OpenWrt 软路由系统（含 OpenClash 规则分流）与红米 AX5 路由器固件救砖**、**原生远程桌面 RDP 与 TightVNC 配置**，以及 **SSH 安全通道、网络诊断调试与抓包分析工具（Whistle）**等进阶玩法。
