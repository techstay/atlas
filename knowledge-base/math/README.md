# 📐 Mathematics 数学与趣味数学

本分类系统化整理了数学学科的通用学习笔记以及精选的初等数学趣味益智习题。

## 📖 学习资源

- [3Blue1Brown](https://www.3blue1brown.com/) — 可视化数学科普频道，用动画解释线性代数、微积分等概念。
- [Student Mathematical Library](https://bookstore.ams.org/stml) — 美国数学会学生数学教材系列。
- [Wolfram|Alpha](https://www.wolframalpha.com/) — 计算知识引擎，可求解数学、物理、工程等问题。
- [Desmos](https://www.desmos.com/?lang=en) — 免费在线图形计算器，适合函数可视化与教学。
- [Symbolab](https://zs.symbolab.com/) — 在线数学求解器，提供代数、微积分等题目的分步解答。
- [John D. Cook 博客](https://www.johndcook.com/blog/) — 数学、统计和数据隐私的深度技术文章。
- [TeX 语法参考](https://mdit-plugins.github.io/zh/tex.html) — Markdown 中 LaTeX 数学公式的语法教程。
