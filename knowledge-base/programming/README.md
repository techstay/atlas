# 💻 Programming 编程语言与核心概念

本分类主要记录了核心编程概念、通用文本处理工具与特定领域的语言实操指南。

## 🛠️ 开发者工具

实用在线工具，覆盖开发日常中的各种小需求。

- [IT Tools](https://it-tools.tech/) — 开发者常用在线工具合集，涵盖加密哈希、编解码、时间戳转换、UUID 生成等。
- [RegExr](https://regexr.com/) — 在线正则表达式学习和测试工具，支持实时匹配高亮。
- [Crontab.guru](https://crontab.guru/) — Cron 表达式可视化生成器。
- [chtml](https://www.chtml.cn/) — 中英文变量命名转换工具，支持驼峰、下划线、帕斯卡等多种命名规范。
- [TAAG](https://patorjk.com/software/taag/) — 文字转 ASCII 艺术字生成器。
- [Glitch Text Generator](https://www.glitchtext.top/zh) — 在线故障艺术字体生成器。
- [cmd5](https://www.cmd5.com/) — MD5 哈希值在线查询和破解数据库。
- [Shields.io](https://shields.io/) — 开源项目徽章生成服务。
- [Djvu2PDF](https://djvu2pdf.com/zh/) — 在线 DjVu 格式转 PDF 工具。
- [QuickRef.me](https://quickref.me/) — 多语言语法速查，涵盖 Bash、Python、JavaScript 等常用语言及工具快捷键。
- [Readme.so](https://readme.so/) — 在线 README 文档生成器，提供章节模板快速创建专业 README。
- [Squoosh](https://squoosh.app/) — 在线图片压缩工具，开源且提供 CLI 和浏览器插件。
- [Screenshot.rocks](https://screenshot.rocks/) — 在线截图美化工具，为截图添加浏览器/移动端界面和精美背景。
- [Carbon](https://carbon.now.sh/) — 代码片段美化工具，生成高质量代码截图。
- [Excalidraw](https://excalidraw.com/) — 在线白板工具，手绘风格图形绘制，开源可自部署。
- [Picsum Photos](https://picsum.photos/) — 占位图片服务，通过参数精确生成测试用图片。

## 🌐 网络工具

### 🌍 IP 与地址查询

- [ifconfig.me](https://ifconfig.me/) — 快速查看本机公网 IP。
- [ipinfo.io](https://ipinfo.io/) — IP 地址详细信息查询，包含地理位置、运营商和 ASN 信息。

### 🔍 HTTP / API 调试

- [httpbin](https://httpbin.org/) — HTTP 请求测试服务，用于调试 API 和客户端请求。

### 🩺 网站与网络诊断

- [Web Check](https://web-check.xyz/) — 网站综合检测工具，一键查看 HTTP 头、DNS 记录、SSL 证书等。
- [ping.pe](https://ping.pe/) — 多节点网络诊断工具。

### 🔗 内网穿透与 DNS

- [SakuraFrp](https://www.natfrp.com/user/) — 国内免费内网穿透工具。
- [dnsprivacy.org](https://dnsprivacy.org/public_resolvers/) — DNS 公共解析服务器列表，支持 DNS over HTTPS/TLS。

## 🎨 前端与设计

CSS、UI 设计、图标、动画等前端开发相关资源。

- [EnjoyCSS](https://enjoycss.com/) — 可视化 CSS3 代码生成器。
- [cssgr.id](https://cssgr.id/) — CSS Grid 布局交互式生成器，可视化设置并输出源码。
- [CSS-Tricks Guides](https://css-tricks.com/guides/) — CSS-Tricks 精选前端开发指南合集。
- [CSS Zen Garden](http://www.csszengarden.com/) — CSS 设计经典案例展示。
- [Landing Page Checklist](https://landingpage.fyi/landing-page-checklist.html) — 着陆页建设清单和工具汇总。
- [CodePen](https://codepen.io/) — 前端代码在线 IDE，即时运行 HTML/CSS/JavaScript，大型开发者社区。
- [Font Awesome](https://fontawesome.com/) — 可缩放矢量图标库，适用于网站图标需求。
- [Loading.io](https://loading.io/) — Loading 动画制作工具，丰富样例库，支持上传图标定制。
- [Colorkit.co](https://colorkit.co/) — 在线颜色组合生成器，支持随机和基于选定颜色生成配色方案。

- [paiza 编程冒险](https://paiza.jp/botchi/) — 日系编程冒险游戏，通过代码指令控制角色生存。
- [Advent of Code](https://adventofcode.com/) — 年度编程挑战活动，每天一道趣味算法题。
- [VisuAlgo](https://visualgo.net/en) — 数据结构与算法可视化工具。
- [GameDB.eth](https://zh.gamedb.eth.limo/) — 链上游戏数据库，查询 NFT 游戏资产和信息。
