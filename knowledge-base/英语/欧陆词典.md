# 📖 欧陆词典（Eudic）

欧陆词典是一款支持多平台的词典/语言学习工具，核心优势在于支持**第三方词库扩展**（mdx / mdd / css 格式），可自由组合权威词典，非常适合英语深度学习。

## 安装与注册

- 官网：<https://www.eudic.net/>
- 免费版功能基本够用，高级功能需购买 VIP

## 自定义词库

#### 社区

- [freemdict](https://forum.freemdict.com/)，国内最活跃的词库社区，有不少资源
- [掌上百科论坛](https://www.pdawiki.com/forum/)

### 添加词库

首先去社区寻找自己心仪的词库，这里给两个例子。免费版的欧陆词典本来也就能添加两个额外词库，刚刚好。

- [精装 - 牛津高阶双解第10版完美版重生版（OALDPEX）](https://forum.freemdict.com/t/topic/43710)
- [朗文当代高级英语辞典 第6版 糖果版 V3.1](https://forum.freemdict.com/t/topic/40024)

1. 下载词典文件（mdx + mdd + css + js），一般词库作者提供的文件都要下载，js 可以执行自定义代码，如果为了安全考虑可以不下载 js
2. 双击 mdx 文件，如果正常安装欧陆词典的话，应该会自动弹出安装对话框，点击安装
3. 重启欧陆词典 → **词典管理** → 勾选启用新词库
4. 调整词典排序，将新添加的词典置顶
