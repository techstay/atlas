# atlas

> **Atlas** /ˈætləs/，古希腊神话中肩负苍穹的泰坦巨神，现代语境中则引申为“地图集、百科全书”。这个命名承载着两层核心愿景：
>
> 1. 作为“扛天巨神”，我们要持续学习新知，承载起个人知识的成长与演进；
> 2. 作为“地图集”，要打造系统化的知识索引，让各类经验可回溯、可复用。

![last commit](https://img.shields.io/github/last-commit/techstay/atlas)

这是我的个人知识图谱，记录我学习过的各类知识、正在实践的项目以及持续探索的技术领域。
